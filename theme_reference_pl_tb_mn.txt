COMPONENT GEOMETRY AND FIXED BEHAVIOR
====================================
PLAYLIST
The panel is right anchored. x2 = window_width - inset_side_pl;
x1 = x2 - width_panel_pl; y1 = inset_top_pl;
y2 = window_height - inset_bottom_pl.
Header ends at y1 + height_header_pl. The search area is present only while search
is active. The toolbar occupies the bottom height_toolbar_pl units.
The list begins 4 units after header/search and ends 4 units above the toolbar.
Visible row count is floor(list_height / height_row_pl).
The bottom OSC exclusion controls edge-hover opening, not playlist panel height.
No theme panel_height_pl lookup exists in this version.

TITLEBAR
Full width, top y=0. Left controls leave the title centered in remaining width;
right controls place the title at x=16. The bar hides in fullscreen.
Traffic-light dot diameter and colors are hardcoded (14 units, standard red/yellow/
green), not theme controls. Symbol icons use Segoe MDL2 Assets.
Only the shown loader branches establish supported style/side behavior.

MENU
Menu width and row counts are clamped at render time. Use the listed render-time
defaults, not pre-render state constants. Invalid alpha strings reset locally.
Menu actions/content belong to menu.conf, not theme fields. Do not turn commands,
script options, or internal variables into invented theme keys.

CROSS-COMPONENT SHARED FALLBACKS
Global/shared keys used by playlist/titlebar/menu include text_color, dim_color,
danger_color, surface_color, accent_color, font_size, font_text, font_ui, font_icon,
size_font_title, alpha_panel_bg, alpha_icon_dim, panel_radius, glass_blur,
radius_glass_blur, border_all_color, border_all_alpha, border_all_width.
Playlist also explicitly reads shared fallbacks row_height,
header_height, search_height, toolbar_height, panel_width, side_inset, top_inset,
bottom_inset, scrollbar_width, hover_strip_width, hide_delay_sec,
exclusion_bottom_osc. These are supported fallback names in that loader; their
presence does not imply equivalent old *_pl spellings are accepted.
Titlebar supports mode_show_titlebar and side_button_titlebar shared fallbacks.

PLAYLIST ADD-POPUP / CROSS-SCOPE SETTINGS
Playlist Add popup shares documented OSC popup colors/borders and uses
popup_hover_color -> color_bg_hover_osc -> color_hover_pl -> accent_color ->
"63B8FF". alpha_popup_hover defaults to "1F".
Its glass toggle is EXACTLY enabled_glass_blur_add_popup (no scope suffix in this
playlist source), inheriting resolved playlist glass when nil. Its blur radius is
radius_glass_blur_add_popup_osc -> resolved playlist blur radius.
Do not silently normalize the unsuffixed toggle into a different key.
